# 台股妖股篩選系統

用證交所、櫃買中心的公開資料，每天找出具有「妖股」特徵的上市櫃股票。
只用 Python 3 內建函式庫，不需要安裝套件，也不需要 API 金鑰。

## 網頁版（妖股雷達）

在 Finder 雙擊 `啟動妖股雷達.command`，或在終端機執行：

```bash
cd ~/tw-yaogu-screener
python3 server.py
```

瀏覽器會自動開啟 http://localhost:8765 。網頁可以：

- 調整最低分數、成交張數、小股本門檻，篩選上市／上櫃；點「ⓘ 評分依據」可看計分規則、各門檻的意義與今天各門檻的檔數
- 只看漲停、排除處置股、搜尋代號或名稱
- 點欄位標題排序；點股票查看得分明細（每一項加幾分）與近 60 日 K 線（含 5 日均線、前 60 日高點）
- 用鍵盤 ↑ ↓ 切換股票

### 即時行情

今天的官方收盤資料還沒公布時（盤中，或收盤後到約 15:00 之間），會改用證交所「基本市況報導」的即時行情（延遲約 5～20 秒）掃描全市場，約需 30～40 秒：

- 盤中每 3 分鐘自動更新全市場，標示「盤中即時」
- 點開的個股每 10 秒更新一次即時報價
- 13:35 之後的快照視為今日收盤；官方資料公布後自動改用官方資料

即時行情不含盤後定價交易，成交量會比官方資料略少；冷門股收盤後若沒有最新成交價，會以委買價估計。

### 明日強勢候選（網址 `#picks`）

收盤後找出「放量突破 60 日高點、收在最高價附近、均線向上，但 5 日漲幅還不到 20%」的股票，
並**排除當天三大法人賣超**的股票（三大法人資料約 15:00 後公布，公布前不排除），每檔列出：

- **為什麼列入候選**：符合的條件與實際數字
- **價位**：進場區間（突破點或收盤 -3% ～ 收盤 +3%）、停損（今日最低，或收盤 -7%）、
  目標一（風險的 1.5 倍，先賣一半並把停損移到成本）、目標二（風險的 3 倍，全部出場），最多持有 3 天
- **風險**：爆量、上影線、注意股、一字漲停買不到等

頁面最上方會顯示這套規則用近 121 個交易日、完全照上述價位進出的回測結果（含交易成本，已排除法人賣超）。
**2 年研究顯示這套規則跟隨便買幾乎沒有差別，請當作觀察名單，不是保證獲利的買進訊號。**
規則寫在 `strategy.py`，可以自行調整條件後看回測數字的變化。

### 起漲前夕（網址 `#pre`）

找出「近 20 日箱型整理（高低差 ≤ 15%）、成交量萎縮（20 日均量 ≤ 60 日均量）、5／10／20 日均線糾結（差距 ≤ 3%），
股價貼近箱頂，今天溫和放量收紅」但**還沒突破**的股票。**大盤（加權指數）跌破 20 日均線時，整頁標示暫停。**每檔列出突破買進價（箱頂上一檔）、停損（箱底，或突破價 -7%）、
目標（箱頂 + 箱型高度），K 線圖上會畫出箱頂與箱底。

頁面上會顯示回測結果（大盤多頭才做、漲過箱頂才進場、5 天內沒突破放棄、最多持有 10 天），
並和「大盤多頭日任意股票隔日買、抱 10 天」比較。**2 年研究顯示型態本身跟隨便買差不多，請當作觀察名單。**

使用期間請保持終端機視窗開著，關掉視窗或按 Ctrl+C 就會停止。

### 2 年研究（`research/`）

`research/download_history.py`、`research/download_extra.py` 下載 2 年股價、加權指數與三大法人資料，
`research/study.py` 把兩套策略加上各種條件後回測：前 75% 期間用來找條件、最後 25% 只用來驗證，
並與同期間任意股票比較，避免把巧合當成規律。結論（2024/08～2026/10）：

- 兩套策略本身都跟隨便買幾乎沒有差別，沒有任何條件能讓訓練期轉為正報酬
- 在兩段期間都成立的只有兩點，已套用：明日強勢候選排除法人賣超；起漲前夕在大盤跌破 20 日均線時暫停

## 網路版（GitHub Pages）

`.github/workflows/update.yml` 會在每個交易日台灣時間 15:40、16:20、17:10、18:30、20:15 自動執行（GitHub 排程可能延遲或被略過，所以安排多次；LINE 同一天只發送一次）：

1. 下載當天行情（前一次的資料存在 GitHub Actions 快取，不用重抓）
2. 執行 `export_site.py`，把篩選結果、明日候選、回測與 K 線資料存成 `site/data/*.json`
3. 發佈到 GitHub Pages

網路版是靜態網頁，沒有盤中即時報價，也不能自訂成交量、股本門檻（固定為 500 張、10 億）。
想立即更新，可以到 GitHub 專案的 Actions 頁面，對「每日更新妖股雷達」按 Run workflow。

本機預覽靜態版：`python3 export_site.py && cd site && python3 -m http.server`

## LINE 通知

每天更新完成後，`notify_line.py` 會把明日強勢候選以可左右滑動的卡片推播到 LINE：
每檔一張卡片（價格、進場區間、停損、目標一／目標二、入選理由、風險、看 K 線按鈕），最後一張是回測成績。
整組卡片只算 1 則訊息額度；若卡片格式被 LINE 拒絕，會自動改傳純文字版。
同一個交易日只發送一次。使用 LINE 官方帳號 Messaging API（LINE Notify 已於 2025 年停止服務），免費方案每月 200 則。

設定方式：

1. 到 [LINE Developers](https://developers.line.biz/console/) 用 LINE 帳號登入，建立 Provider，再建立 **Messaging API** channel（會同時建立一個 LINE 官方帳號）
2. 在 channel 的 **Messaging API** 分頁最下方，發行 **Channel access token (long-lived)**
3. 在 **Basic settings** 分頁最下方，複製 **Your user ID**（U 開頭）
4. 用手機 LINE 掃 **Messaging API** 分頁的 QR code，把官方帳號加為好友
5. 把兩組值存成 GitHub Secrets：

```bash
gh secret set LINE_CHANNEL_ACCESS_TOKEN --repo ghiting76914-sys/tw-yaogu-screener
gh secret set LINE_USER_ID --repo ghiting76914-sys/tw-yaogu-screener
```

預覽訊息內容：`python3 notify_line.py --dry-run`

## 命令列版

```bash
python3 yaogu.py                    # 最近交易日（建議 15:00 收盤資料公布後執行）
python3 yaogu.py --date 20260930    # 指定日期
python3 yaogu.py --min-score 8      # 只看高分
python3 yaogu.py --small-cap 5      # 小股本門檻改為 5 億
```

第一次執行會下載約 121 個交易日的行情，需要幾分鐘（證交所限制請求頻率）。
之後會讀取 `data/cache/` 裡的快取，每天只需要補抓當天的資料。
結果會印在終端機上，完整清單另存成 `output/yaogu_YYYYMMDD.csv`，可以直接用 Excel 開啟。

## 評分規則

| 條件 | 分數 |
|---|---|
| 股本 < 10 億 / < 20 億 | +2 / +1 |
| 量比（當日量 ÷ 前 20 日均量）≥ 3 / ≥ 2 | +2 / +1 |
| 漲停（漲幅 ≥ 9.5%），連續漲停每多一天再 +1（最多 +3） | +2 起 |
| 未漲停但漲幅 ≥ 5% | +1 |
| 5 日漲幅 ≥ 20% / ≥ 10% | +2 / +1 |
| 收盤突破前 60 日最高價 | +2 |
| 週轉率 ≥ 10% | +1 |
| 列入注意股 | +1 |
| 處置股 | 只標示，不加分 |

預設只列出分數 ≥ 6、成交量 ≥ 500 張的一般股票（排除 ETF、權證）。
評分邏輯集中在 `yaogu.py` 的 `analyze()`，可以依自己的需求調整。

## 參數

| 參數 | 預設 | 說明 |
|---|---|---|
| `--date` | 今天 | 篩選日期 YYYYMMDD |
| `--min-score` | 6 | 最低分數 |
| `--top` | 50 | 終端機最多顯示幾檔 |
| `--min-volume` | 500 | 最低成交張數 |
| `--small-cap` | 10 | 小股本門檻（億元） |
| `--lookback` | 61 | 抓取的交易日數 |

## 每天自動執行（選用）

用 crontab 在平日 15:30 執行：

```
30 15 * * 1-5 cd ~/tw-yaogu-screener && /usr/bin/python3 yaogu.py >> output/cron.log 2>&1
```
